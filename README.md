# Peygamberler Tarihi - Kurulabilir Web Uygulaması (PWA)

## Nasıl Telefona İndirilir / Kurulur?

### Android (Chrome):
1. Bu klasörü bir web sunucusuna yükleyin (veya yerel olarak test edin).
2. Telefonda Chrome ile siteyi açın.
3. Menüden **"Ana ekrana ekle"** veya **"Yükle"** seçeneğine tıklayın.
4. Uygulama ana ekrana ikon olarak eklenir ve offline çalışır.

### iPhone (Safari):
1. Safari ile siteyi açın.
2. Paylaş butonuna (kare ok) tıklayın.
3. **"Ana Ekrana Ekle"** seçin.
4. Uygulama ana ekrana eklenir.

## Dosyalar
- `index.html` - Ana sayfa
- `app.js` - Uygulama mantığı + Service Worker kaydı
- `data.js` - Tüm peygamber hikayeleri (TR + EN)
- `styles.css` - İslami tasarım
- `manifest.json` - PWA ayarları
- `sw.js` - Offline desteği
- `icon-192.png` & `icon-512.png` - Uygulama ikonları

Uygulama tamamen offline çalışacak şekilde hazırlanmıştır.
